# 접지 페르소나 합성 데이터 증강 연구 — 설계 초안 v0.1 (2026-08-03)

## 연구 질문

통계적으로 접지된 페르소나(NVIDIA Nemotron-Personas-Korea)로 조건화하여 생성한
합성 지시 데이터가, 무페르소나 및 임의 페르소나 데이터 대비 소형 한국어 모델의
미세조정 결과 — 응답 다양성과 인구 하위집단 강건성 — 를 개선하는가.

## 기여 (예정)

1. 페르소나 **접지 여부**를 처치로 삼은 통제 실험. Persona Hub(Ge et al. 2024,
   arXiv:2406.20094)는 웹 유래 페르소나로 다양성 향상을 보였으나 인구 대표성
   근거가 없고, 접지/비접지 통제 비교는 부재하다.
2. Nemotron-Personas-Korea의 공식 용도(소버린 AI 학습 데이터 다양화·편향 완화)에
   대한 첫 실증.
3. 한국어 소형 모델의 하위집단(고령·농촌 등) 응답 품질 강건성 평가.

기존 투고작과의 구분: persona-validation(IEEE Access)과 ai-comparison(ETRI J)은
전부 추론 시점 평가 연구이며, 본 연구는 프로그램 내 유일한 학습(미세조정) 연구다.

## 설계

처치 3조건 — 생성 데이터만 다르고 생성기·시드 과제·규모·학습 절차는 동일:

| 조건 | 페르소나 | 목적 |
|---|---|---|
| C0 | 없음 | 합성 데이터 기본선 |
| C1 | 임의(인구통계 필드 균등 무작위 조합) | "페르소나 유무" 효과 분리 |
| C2 | Nemotron 접지(성별x연령 층화, 실분포 비례 추출) | 처치 |

C1이 핵심 대조군이다: C2의 효과가 페르소나 유무가 아니라 **접지 여부**에서
오는지를 분리한다(베이스라인 규율, 프로그램 규약 계승).

- 생성기: **K-EXAONE 2.0**(LGAI-EXAONE/K-EXAONE-2.0-750B-A37B, 2026-07-31 공개,
  Apache 2.0) — 출력물의 타 모델 학습 사용에 라이선스 제약이 없다. 서빙은
  FriendliAI(1.0을 day-0 지원했던 경로, 기존 EXAONE_API_KEY 인프라 재사용) 확인
  후 확정. 미확정 시 폴백: K-EXAONE 1.0(236B-A23B, 검증 완료된 기존 경로).
  - HCX-007은 생성기에서 **제외**: CLOVA Studio 이용약관이 "허용하는 범위 밖에서
    언어모델의 학습 또는 개발하거나 제3자에게 본 서비스의 결과물을 제공하여
    제3자가 언어모델의 학습 또는 개발할 수 있게 해서는 안 됩니다"라고 명시
    (2026-08-03 확인). 이 제약 자체를 논문의 실무적 논점(상용 API 합성 데이터의
    약관 리스크)으로 기록한다.
- 시드 과제 스키마: 과제 유형 k종(정보 질의, 조언, 설명, 일상 대화 등)을 조건 간
  동일하게 두고 페르소나 부분만 교체. 파일럿에서 유형 목록 확정.
- 규모: 조건당 N=10,000 지시-응답 쌍(파일럿 후 확정).
- 미세조정 대상: LGAI-EXAONE/EXAONE-3.5-2.4B-Instruct, LoRA(하이퍼파라미터
  사전등록 시 고정), 조건당 학습 시드 2회 반복 → 6 runs + 원 모델 = 7 평가 대상.

## 평가 4축

1. **다양성**: distinct-n, Self-BLEU, 임베딩 분산. 생성 데이터 자체(중간 점검)와
   조정 후 모델의 개방형 응답(주 결과) 양쪽에서 측정.
2. **하위집단 강건성**: 하위집단 축(연령·지역 중심) 조건 질의에 대한 응답 적합성을
   LLM 심판이 채점, 집단 간 격차 지표로 요약. 심판은 ai-comparison 다심판 체계의
   축소판(주심판 2인) + 사람 검증 표본(블라인드).
3. **일반 능력 유지**: KoBEST·KMMLU 부분집합으로 비열등성 확인
   (ai-comparison 하네스 재사용).
4. **지시 이행**: 형식 지시 불이행률(선행 연구 지표 재사용).

## 가설 (사전등록 시 고정)

- H1: C2 데이터는 C0·C1 대비 어휘·의미 다양성이 높다 (데이터 수준).
- H2: C2로 조정한 모델은 하위집단 응답 적합성 격차가 작다 (모델 수준, 주 가설).
- H3: 조건 간 일반 능력 차이는 사전 정의한 비열등 범위 내다 (안전성).

## 절차

Phase 0 파일럿(조건당 200쌍, 파이프라인·비용·약관 검증) → OSF 사전등록
→ 본 생성 → 미세조정 → 평가 → 집필. 사전등록 전 본 실험 금지.

## 비용 추정 (파일럿에서 확정)

- 생성: 3만 호출 x 평균 출력 ~500토큰. HCX-007 선행 실측(약 18,000원/1.6만 호출,
  짧은 출력) 외삽 시 수만~십수만 원 규모. CLOVA Studio 단가 재확인.
- 미세조정: 2.4B LoRA, run당 A100 2~4 GPU시간 x 6 runs — 클라우드 $50~150.
- 심판 채점: 하위집단 질의 ~1,000응답 x 7 대상 — 선행 단가 기준 $30~60.

## 관련연구 확인 (2026-08-03 조사)

인접 선행연구 4건 확인. 핵심 교집합(접지 페르소나 x 미세조정 x 접지 여부 통제
x 하위집단 강건성)은 공백으로 확인됨.

1. **NTT DATA x Nemotron-Personas-Japan** (2026-02, NVIDIA HF 블로그 + NTT DATA
   기술 기고, 비동료심사): 일본판 접지 페르소나 500개로 시드 450개 → 13.8만
   예제 확장, tsuzumi 2 미세조정, 법률 QA 15.3%→79.3%. 가장 가까운 선례이므로
   서론에서 정면 인용: "실행 가능성은 보였으나 처치가 확장 여부이지 접지 여부가
   아님(무페르소나·임의 페르소나 대조 부재)"로 포지셔닝.
2. **Kambhatla 외, Findings of EMNLP 2025** (pp.21024-21033): 페르소나 생성
   데이터의 어휘 다양성 측정. 페르소나>무페르소나이나 fine-grained 세밀화의
   추가 이득은 미미. 접지 차원 없음, 학습 실험 없음. **H1 경고 시그널** — 주
   가설을 H2로 유지하고 H1 기각 시에도 성립하는 서술 구조 필요. 이 논문의
   다양성·중복도 지표 스위트를 평가 1축에 차용할 것.
3. Persona Hub(Ge et al. 2024) / Tulu 3(Lambert et al. 2025): 방법론 원조와
   실전 채택. 접지·통제 비교 없음.
4. Socially-Grounded Persona Framework(arXiv:2601.07110, 2026-01): 접지 필요성
   주장 논문(시뮬레이션 맥락, 학습 실험 없음) — 문제의식 지지 인용원.
5. 한국어권: Nemotron-Personas-Korea 학습 활용 연구 없음(시뮬레이션·도구만).

## 프레임 보강 (2026-08-03)

생성(K-EXAONE 2.0) → 학습(EXAONE-3.5-2.4B) 전 단계가 한국계 오픈 모델로 구성되어
"완전 개방형 소버린 AI 데이터 파이프라인" 실증이라는 서사가 성립한다. K-EXAONE
2.0이 공개 직후(2026-07-31)라 시의성도 확보된다. HCX-007 배제 사유(상용 API 약관)
는 실무적 논점으로 논문에 기록한다.
