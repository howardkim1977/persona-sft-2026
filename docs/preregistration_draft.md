# 사전등록 초안 v0.2 (OSF 등록용, 2026-08-04)

제목(가): 통계적으로 접지된 합성 페르소나 조건화가 소형 한국어 언어모델
미세조정에 미치는 효과: 무페르소나 및 임의 페르소나 대비 통제 실험

상태: v0.2 — 확정 대기 항목 전부 해소(2026-08-04 사용자 결정). 등록 가능
상태. 등록 후에는 본 문서의 확증적(confirmatory) 항목을 변경하지 않는다.

---

## 1. 연구 질문

실제 인구통계 분포에 접지된 합성 페르소나(NVIDIA Nemotron-Personas-Korea)로
조건화하여 생성한 지시-응답 학습 데이터가, (a) 페르소나 없이 또는 (b) 임의
조합 인구통계 페르소나로 생성한 데이터 대비, 소형 한국어 언어모델의 미세조정
결과를 개선하는가.

## 2. 가설

- **H1 (어휘 다양성, 확증적)**: C2 데이터로 조정한 모델의 개방형 응답은
  C0·C1 조정 모델 대비 어휘 다양성이 높다. 어휘 다양성은 5개 지표(distinct-1,
  distinct-2, distinct-3, 쌍별 self-BLEU, zlib-9 압축비)로 조작적 정의하며,
  5개 중 4개 이상에서 부트스트랩 95% CI가 0을 배제하는 방향 차이를 지지
  기준으로 한다. 생성 데이터 자체의 동일 지표는 조작 점검(manipulation
  check)으로 보고한다.
  - 근거와 위험: 파일럿(조건당 200쌍)에서 데이터 수준 5지표 모두 C2>C1>C0
    방향 확인. 단 C2-C1 격차가 작아(선행 문헌과 일치) 기각 가능성 있음 —
    기각되어도 H2가 성립하면 연구는 성립한다.
- **H2 (하위집단 강건성, 주가설, 확증적)**: C2 조정 모델은 C1·C0 조정 모델
  대비, 하위집단(고연령·비수도권) 화자 질의에 대한 응답 적합성의 집단 간
  격차가 작다. 격차 = (기준집단 평균 점수 - 하위집단 평균 점수).
- **H3 (일반 능력 비열등, 확증적)**: 조건 간 일반 벤치마크 정확도 차이는
  비열등 마진(-2.0%p) 이내다.
- **탐색적 지표**: 임베딩 분산(gemini-embedding-001, 768차원, 쌍별 코사인
  거리·중심 거리) — 파일럿에서 평탄~미세 역전이 관찰되어 확증 가설에서
  제외하고 탐색적으로 보고한다(효과 경로가 어휘·화용 층위라는 해석 검증).
  말투 사용역 적합성 채점도 탐색적으로 병기한다.

## 3. 설계

처치 3조건. 생성 데이터의 페르소나 조건화 방식만 다르고 그 외 전부 동일.

| 조건 | 페르소나 | 구성 |
|---|---|---|
| C0 | 없음 | 과제 유형만 제시 |
| C1 | 임의: 인구통계 5필드(성별, 연령 19~89, 시도 17, 직업 12, 학력 7) 균등 무작위 조합 | 선행 silicon sampling 관행 재현 |
| C2 | 접지: Nemotron-Personas-Korea 공개본(100만 행)에서 균등 저수지 표본(시드 고정) — 원자료가 실분포 합성이므로 균등 추출 = 실분포 비례 | 26필드 중 기본정보 + 요약 + 성장·생활배경 + 취미·관심사 + 직업 성향을 프롬프트 블록으로 사용 |

- 규모: 조건당 10,000쌍(과제 8종 x 1,250). 과제 유형 목록과 배정은 조건 간
  동일. 과제 8종: 정보질의, 조언요청, 설명요청, 일상대화, 글쓰기, 계획수립,
  추천요청, 문제해결 (tasks.py v0.1에 고정).
- C2 학습용 페르소나와 평가용 페르소나는 uuid 수준에서 분리(중복 배제).

  - 배제 근거 기록: 상용 폐쇄 API 전부(출력물의 타 모델 학습을 약관이 금지 —

- 형식 실패 시 동일 프롬프트 최대 3회 재생성. JSON 파싱은 strict=False +
  정규식 폴백(tasks.py). 3회 실패 항목은 결측 기록 후 대체 표본으로 보충하고

- 품질 필터(조건 공통, 동일 규칙): (i) instruction 20자 미만 또는 response
  50자 미만 제외, (ii) 한글 비율 50% 미만 제외. 필터 통과율을 조건별 보고.

## 5. 미세조정

## 6. 평가

### 6.1 H1: 응답 어휘 다양성

- 평가 프롬프트: 홀드아웃 개방형 프롬프트 500개(과제 8종 균등, 페르소나
  비조건화 - 중립 질의). 각 모델이 1회씩 응답(temperature 0.7 고정).
- 지표 5종(2절)을 모델별 계산, 조건 간 차이는 프롬프트 대응 부트스트랩
  (10,000회) 95% CI.

### 6.2 H2: 하위집단 응답 적합성 (주분석)

- 평가 질의: 평가 전용 C2 홀드아웃 페르소나에서 하위집단 축별 층화 추출.
  - 연령 축: 60대 이상 vs 40대 미만, 각 100명
  - 지역 축: 비수도권 vs 수도권(서울·경기·인천), 각 100명
  - 각 페르소나당 과제 1종 배정 → 축별 200문항, 총 400문항(중복 축 허용).
  - 질의 생성: 페르소나 조건화 생성(생성기 동일)에서 instruction만 사용.
- 채점: 각 평가 대상 모델의 응답을 심판 2인(openai/gpt-5.6-sol,
  anthropic/claude-opus-5, temperature 0)이 채점.
  - 내용 적합성(0-3): 질의의 상황·요구에 대한 응답의 충실성과 유용성
  - 사용역 적합성(0-3, 탐색적): 화자의 연령·배경에 맞는 어휘·존대 선택
  - 파일럿에서 0-2 척도가 천장에 닿아 0-3으로 세분화함.
- 주지표: 조건별 (기준집단 평균 - 하위집단 평균) 내용 적합성 격차.
  H2 지지 기준: C2 격차 < C1 격차 및 C2 격차 < C0 격차, 각각 문항 대응
  부트스트랩 95% CI가 0을 배제.
- 심판 구성(확정): 주심판 2인 + 보조심판 2인의 4심판 체제(선행 연구의 검증된
  구조와 동일).
  - 주심판(확증 지표 산출): openai/gpt-5.6-sol, anthropic/claude-opus-5
    (temperature 0). 주지표는 주심판 2인 평균.
  - 보조심판(탐색적): openai/gpt-5.2, **HCX-007(CLOVA Studio)** — 4심판 순위
    안정성 확인 및 한국계 vs 글로벌 심판의 사용역 채점 일치도 관찰(탐색적).
    HCX-007은 한국어 문화·사용역 관점의 심판 다양성 확보 목적이며, 채점 점수는
    모델 학습·선택에 일절 개입하지 않는 평가 전용 사용이다(체크포인트 선택은
    검증 손실, 품질 필터는 규칙 기반 — CLOVA Studio 약관의 출력물 학습·개발
    금지 조항과 구분됨을 명시).
- 심판 타당성(사람 채점 없음 — 확정): 본 연구는 사람 채점을 수행하지 않는다.
  대신 (i) 주심판 2인 간 일치도(QWK, Kendall tau) 보고, (ii) 4심판 순위 안정성
  확인(탐색적), (iii) 동일 주심판 프로토콜(sol + opus 계열)이 선행 연구에서
  사람 조정 채점과 QWK 0.80~0.86으로 검증된 이력을 인용한다. 사람 채점 부재는
  한계로 명시한다.

### 6.3 H3: 일반 능력 유지

- KoBEST 5과제 + KMMLU 층화 부분집합 2,000문항(ai-comparison 하네스 재사용,
  시드 고정 추출). 지표: 정확도. 조건별 시드 2 runs 평균.
- 비열등 기준: (C2 평균 - C0 평균) 및 (C2 - C1)의 클러스터(문항) 부트스트랩
  95% CI 하한 > -2.0%p.

### 6.4 지시 이행(보조)

- H1 평가 응답에서 형식 지시(길이 제한, 목록 형식) 이행률을 조건별 보고.

## 7. 분석 계획 요약

- 모든 확증 검정은 위 6절에 명시된 지표·기준으로만 수행한다.
- 시드 2 runs는 평균으로 요약하되 run별 수치를 부록에 전량 보고한다.
- 다중비교: H1 5지표는 4/5 동방향 CI 기준(2절), H2는 축별(연령, 지역) 2회
  검정을 각각 보고(주장은 연령 축 우선, 지역 축은 공동 주지표).
- 제외 규칙: 심판 채점 실패(형식 오류 3회) 문항은 해당 문항 전 모델 제외.
- 그 외 모든 분석은 탐색적으로 명시하고 확증 결과와 구분해 서술한다.

## 8. 이미 수행된 작업의 공개 (사전등록 시점 기준)
